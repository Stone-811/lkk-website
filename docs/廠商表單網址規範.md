# 廠商表單網址規範

給行銷/合作對接用。組廠商預約表單網址時，**請照這份固定用語**，避免同一來源出現多種寫法（如 網站 / website / 官網）造成後台名單來源分裂。

## 兩種表單，同一套規則

| 表單 | 網址 | 變體設定檔 | 後台 |
|---|---|---|---|
| 客戶預約（體驗課） | `/booking?v=…&src=…` | `config/bookingVariants.ts` | 客戶預約 `/admin/leads` |
| 團體課報名 | `/group-booking?v=…&src=…` | `config/groupClassVariants.ts` | 團課預約 `/admin/group-classes` |

兩者的 `?v=` / `?src=` 用法完全一致，**變體 key 也刻意取同名**（`abbott`、`nanshan`），
同一檔廠商活動可以同時給兩條連結，後台用同一組「公司／來源」篩選對得起來。

## 網址格式

```
https://lkkwellness.com/booking?v=<公司變體>&src=<來源>
https://lkkwellness.com/group-booking?v=<公司變體>&src=<來源>
```

- `?v=` → 決定**表單長相**（Hero 文案、是否全齡免費／鎖定門店…），對應各自的變體設定檔
- `?src=` → 決定**這筆名單的「來源」**（後台「來源」欄、`leads.payload.leadSource`）
- 兩者都會**寫進 Firestore 名單**，後台看得到、CSV 匯得出

## 目前可用的公司變體（`?v=`）

### `/booking` 客戶預約（`config/bookingVariants.ts`）

| `?v=` | 公司 | 表單特性 |
|---|---|---|
| `abbott` | 亞培 | 全齡免費、不鎖店、隱藏得知管道；預設來源 LINE |
| `nanshan` | 南山 | 全齡免費、不鎖店、隱藏得知管道；預設來源 網站 |

### `/group-booking` 團體課報名（`config/groupClassVariants.ts`）

| `?v=` | 公司 | 表單特性 |
|---|---|---|
| `abbott` | 亞培 | Hero 換文案、隱藏得知管道；預設來源 LINE |
| `nanshan` | 南山 | Hero 換文案、隱藏得知管道；預設來源 網站 |

團課變體另支援 `lockStore`（鎖定門店，填『南京店』即可）與 `lockCourse`（鎖定課程），
設定後該欄位改成唯讀卡片、不再讓填單人選。

> 加新公司＝在對應的變體設定檔加一段設定（不用改主程式）。未知的 `?v=` 會自動 fallback 成預設表單。

## 來源固定用語（`?src=`）— **請只用這些**

| `?src=` 值 | 代表 |
|---|---|
| `網站` | 官網／網站連結（＝南山預設，不帶 src 就是這個） |
| `LINE` | LINE 群發／官方帳號訊息 |
| `Facebook` | Facebook 貼文／廣告 |
| `Instagram` | Instagram |
| `Email` | 電子報／EDM |
| `傳單` | 實體 DM／傳單（含 QR code） |
| `Google` | Google 搜尋／廣告 |

**規則：**
1. **品牌名用官方寫法**：`LINE`、`Facebook`、`Instagram`（大小寫照這樣）。
2. **一般管道用上表固定中文字**：官網／網頁／website → **一律 `網站`**；電子報 → **`Email`**。
3. **不要自創同義詞**。要新增來源類別，先更新這份清單再用。
4. `?src=` 省略時 = 用該變體的預設來源（南山＝網站、亞培＝LINE）。

## 常用網址範例

```
南山 · 網站   ：https://lkkwellness.com/booking?v=nanshan
南山 · LINE   ：https://lkkwellness.com/booking?v=nanshan&src=LINE
南山 · Email  ：https://lkkwellness.com/booking?v=nanshan&src=Email
亞培 · LINE   ：https://lkkwellness.com/booking?v=abbott
亞培 · Facebook：https://lkkwellness.com/booking?v=abbott&src=Facebook

團課 南山 · LINE ：https://lkkwellness.com/group-booking?v=nanshan&src=LINE
團課 亞培 · 傳單 ：https://lkkwellness.com/group-booking?v=abbott&src=傳單
```

> 需要縮短網址時用外部工具（reurl.cc / bit.ly）即可，`?v=`/`?src=` 參數會保留。

## （選用）要同時給 Google Analytics 追蹤

在後面再接標準 UTM 參數（會另存進 `leads.payload.utm`，不影響上面的 `?v=`/`?src=`）：

```
...&utm_source=nanshan&utm_medium=line&utm_campaign=nanshan_2026
```
