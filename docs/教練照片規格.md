# 練健康官網 — 教練照片規格（給攝影／設計廠商）

## 一句話重點
> **這次照片「跑版」不是尺寸問題，是「構圖不一致」** —— 現有 43 張教練圖尺寸全都一樣（500×550 px），但有些人拍得比較遠、人在畫面裡偏小，排在一起就不整齊。新照片請把**景別與人物大小統一**。

---

## 1. 尺寸 / 像素

| 項目 | 規格 |
|------|------|
| 現況尺寸 | **500 × 550 px**（比例約 10:11，接近直式方形） |
| 建議尺寸 | **1000 × 1100 px**（同比例 2 倍，Retina 螢幕更清晰） |
| 比例 | 維持 **10:11**（寬:高 = 500:550），全部教練一致 |

> 只要比例一致（10:11），尺寸放大不影響版面，只會更清楚。

## 2. 檔案格式

| 項目 | 規格 |
|------|------|
| 格式 | **JPG**（人像照建議，檔案小）或 **PNG** 皆可 |
| 品質 | JPG 品質 80–90%，單張建議 < 300 KB |
| 命名 | 英文小寫，如 `lin-xueli.jpg`（沿用現有命名） |

## ⚠️ 重要：照片「不要燒名字／文字橫幅」

現有照片底部都燒了「教練｜XXX」的深色名字橫幅，但**網站本身已經會用文字顯示教練名字**（在照片下方），造成**名字重複**，也讓照片無法自由裁切。

**新照片請提供純人像、無任何文字／橫幅／浮水印**，名字交給網站顯示即可。

## 3. 構圖（最重要 — 這才是跑版主因）

- **景別統一**：所有教練都用**同一種景別** —— 頭頂到上胸（大頭／半身照），人物大小一致。
- **置中**：人物**水平置中**，眼睛約在畫面**上 1/3**，頭頂留一點空間。
- **左右留白**：網站卡片是 **3:4 直式**、採 `object-cover`，會**自動裁掉左右約 15%**，所以主體務必置中，左右邊緣不要放重要內容。
- **姿勢統一**：全體教練同一種姿勢（例如交叉手臂或自然垂手），排在一起才整齊。
- **背景統一**：同色乾淨背景或統一實景，整排視覺一致。

## 5. 用途說明（供構圖參考）

同一張照片會出現在兩個地方，都用 `object-cover` 置中裁切：

| 位置 | 顯示比例 | 裁切方式 |
|------|---------|---------|
| 教練列表卡片 | 3:4 直式 | 裁掉左右 |
| 教練詳情彈窗頭像 | 1:1 正方 | 裁成方形 |

→ 只要**人物置中、頭到胸**，兩種裁切都好看。
